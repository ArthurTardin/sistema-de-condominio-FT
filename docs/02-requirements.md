# Requisitos do sistema

## Requisitos Funcionais

### Usuários e Autenticação

### RF01 - Gerenciamento de usuários
O sistema deve permitir o cadastro e gerenciamento dos usuários do condomínio.

### RF02 - Autenticação
O sistema deve permitir que o usuário realize uma autenticação para acessar suas funcionalidades.

### Estrutura física

### RF03 - Gerenciamento de unidades
O sistema deve permitir o cadastro e gerenciamento das unidades do condomínio.

### RF04 - Gerenciamento de apartamentos
O sistema deve permitir o cadastro e gerencimento de apartamentos disponíveis nas unidades do condomínio.

### RF05 - Gerenciamento de espaços
O sistema deve permitir o cadastro e gerenciamento dos espaços comuns disponíveis no condomínio.

### Reservas

### RF06 - Reserva de espaços
O sistema deve permitir que usuários autorizados realizem reservas dos espaços disponíveis.

### RF07 - Regras do espaço
O sistema deve informar regras de utilização do espaço.

### RF08 - Cancelamento de reservas
O sistema deve permitir o cancelamento de reservas conforme as regras definidas pelo condomínio.

### Comunicação

### RF09 - Gerenciamento de avisos
O sistema deve permitir o cadastro e gerenciamento de avisos, pelo administrador, no condomínio.

### Ocorrências e Chamados

### RF10 - Registro de ocorrências pelo administrador
O sistema deve permitir que moradores registrem ocorrências relacionadas ao condomínio. O sistema deve permitir também que o administrador registre ocorrências recebidas por outros canais (telefone, presencial).

### RF11 - Abertura de chamados
O sistema deve permitir que moradores abram chamados para solicitar atendimento ou manutenção.

### RF12 - Atribuição de chamado
O sistema deve permitir que o administrador atribua o chamado a um funcionário.

### RF13 - Gerenciamento do chamado
O sistema deve permitir que o funcionário gerencie o chamado e sua solução.

### RF14 - Histórico de chamados
O sistema deve manter o histórico de alterações do chamado, deve ser visualizado pelo administrador e funcionários.

### Financeiro

### RF15 - Gerenciamento de taxa condominial
O sistema deve permitir que o administrador cadastre e gerencie o valor da taxa condominial por unidade/apartamento.

### RF16 - Consulta de status de pagamento
O sistema deve permitir que o morador visualize o status de pagamento (pago/pendente) da taxa condominial de sua unidade.

### Calendário e Notificações

### RF17 - Calendário
O sistema deve disponibizar um calendário do condomínio com reservas, eventos e avisos, por dia, semana e mês.

### RF18 - Notificações 
O sistema deve notificar o morador e funcionário sobre reservas, alteração nos chamados e avisos.

### Dashboards

### RF19 - Dashboard administrativo
O sistema deve permitir que o administrador e funcionários visualize quantidade de moradores, chamados por status, reservas, ocorrências em estatísticas.
